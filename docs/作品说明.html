我具体做了什么（AI 做了什么、我否掉了什么）

  • 先定结构再让 AI 写：先想清页面要回答评审的四个问题，把每节内容写成中文要点，再让 AI 实现版式——反过来会得到漂亮但没有信息的页面。
  • 不让 AI 编数据：星标是脚本抓的；3DGS 的点数、PSNR、帧率是跑出来的；上游示例没有指标就如实写"未测"，不套用论文数字。
  • AI 的方案被我退回两次：项目雷达先用爬虫抓 GitHub → 我改成官方 API；接口限额没处理 → 改成已授权令牌 + 结果落文件。
  • 发现筛选逻辑不严，自己补规则：抓回 138 个仓库里混着人脸识别、扫地机器人等不相关项目 → 我加「相关性关键词 + 人工否决清单」，重抓到 116 个。
  • 不接受"跑起来了就算完成"：要求每步留下证据——注册率不足就报错、空画布不许算通过（用像素统计判定）。
  • 主动放弃并记录：全分辨率 30000 步实测每步 3.6 秒（约 30 小时）→ 停掉，把数字记进文档，而不是硬跑。

怎么验证的（都是真实运行的输出，不是"应该没问题"）

  • 训练链路端到端跑通：手机照片 → COLMAP 稀疏重建 → 云端 GPU 上 gsplat 训练 30000 步（渲染分辨率 2016×1512）→ 导出上网版资产 → 网页实时渲染 → 指标回写数据库。
  • 三组对照实验，不是无限调参：同一批数据在云端跑三组（半分辨率全量稠密化 64.8 万高斯 / 全分辨率保守稠密化 1.5 万高斯 / 全分辨率中等稠密化 6.7 万高斯），留出视角 PSNR 分别为 14.46 / 14.52 / 14.44 —— 显存从 1.5 GB 换到 31 GB，画质几乎没动，据此把瓶颈定位到拍摄而非算力，避免了继续烧钱。
  • 两次有针对性的改进，各值多少也如实记了：① 后处理清掉浮动点与大团子（视觉更干净，细节不变多）；② 剔除 6 张最糊的照片重训（留出视角 14.44 → 15.41 dB，SSIM 0.7333 → 0.7567，线上场景 shoe-37 就是这个版本）。两版留出视角不同、不能逐张对比，能对比的只有平均指标——这句话我写进了页面里。
  • 查出一个真实的评估缺陷并修掉：原先「留出 8 个视角」取的是最后 8 个，实测它们是一整段连续弧（约占环绕 70°）→ 这一段完全没有参与训练，而网页查看器是让访客自由环绕的，第一眼就撞上盲区。改成按相机绕主体的方位角均匀留出后，留出的 8 个视角散开到整圈。
  • 数据一致性可对账：数据库里的高斯点数 × 32 字节 = 资产实际字节数，逐字节吻合；上线后用 md5 比对线上与本地资产，两处入口一致（今天这次可访问性修复也是这么验的）。
  • 像素级判空：用「亮像素占比 + 标准差 + 重心」区分"真渲染出来"和"加载成功但全黑"。
  • 后端是真的：空库返回 200 而非 404、重复 slug 409、未知场景 404、限流 429 + Retry-After、带链接的留言 400 拒收（各种写法都覆盖）、UTF-8 往返、时区分桶、CORS 白名单——都有对应测试；XSS 载荷实测只以文本呈现、DOM 无注入节点。

已知边界（不想含糊过去）

  • 自训场景的画质瓶颈在拍摄，不在算力（这是我这轮最想讲清楚的结论）：同一批 43 张手机照片（COLMAP 注册 39 张， 其中 6 张被清晰度检查判为糊片，实际参与训练 31 个视角），在云端 31 GB 显存上跑满 30000 步、全分辨率渲染， 留出视角 PSNR 仍只有 14.4–15.4。网页里能认出是鞋，但边缘偏软、背景有杂点； 同一个查看器加载官方示例是清晰的，说明问题不在查看器或部署。真正的解法是重拍 （视角加密到 50–80 张、避免糊片、贴近平移、背景干净），而不是加高斯、加步数或换更大的卡——这三条我都实测否掉了。
  • 本机显存上限（实测，它决定了能做什么）：WSL 下 GPU 单进程可分配显存只有约 1.5 GB（标称 8 GB；驱动报的"空闲"数不可信）， 且与 Windows 可用内存强相关（实测 700 MB ↔ 2.7 GB）。结论：单物体 / 桌面级可行（3–5 万高斯即可）， 房间级不行（参考实现需 100–300 万高斯）。已用公开数据集（Mip-NeRF 360，240 张真实照片、自带 COLMAP 位姿） 把同一条管线跑通验证：流程全绿、跳过 SfM 只要 15 分钟，但只塞得下 6.6 万高斯，画质糊（PSNR 11.6）， 因此主动没有上线——证据与数据都在仓库里。
  • 展示中的实拍场景就是我自己拍的运动鞋：43 张手机环拍 → 降采样与亮度归一 → COLMAP → 云端 30000 步训练 → .splat 上网。三个版本同屏呈现（原版 / 后处理版 / 剔糊片重训版），并在简介里写清每版的差别； 另有一个 15 个视角的「保温杯」场景作为受限对照（PSNR 10.4），用来佐证"输入决定上限"。
  • 免费额度的边界：后端跑在 EdgeOne 云函数 + Neon 免费版 Postgres（计算空闲自动挂起、下次连接自动唤醒）， 月额度对个人作品站足够，但不是为高并发准备的。
